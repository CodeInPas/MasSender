> # PasMail - Enterprise-Grade Bulk Emailer
> 
> 
> PasMail is an open-source, multi-threaded desktop application designed for safe and automated bulk email campaigns. Built entirely with native **Lazarus FPC** and **SQLite**, it guarantees high performance and low memory footprint. It includes advanced features usually found in premium SaaS, such as **Smart Circuit Breaker** to protect your SMTP reputation, **Gemini AI Spintax Generator** for dynamic email personalization, and **Automated SMTP Warm-up**.

**Indonesia:**

> # PasMail - Enterprise-Grade Bulk Emailer
> 
> 
> PasMail adalah aplikasi desktop open-source yang dirancang untuk mengelola kampanye email massal secara otomatis dan aman. Dibangun sepenuhnya menggunakan **Lazarus FPC** (native) dan **SQLite**, aplikasi ini menjamin performa tinggi tanpa membebani RAM. PasMail dilengkapi fitur kelas atas seperti **Smart Circuit Breaker** untuk menjaga reputasi SMTP, **Gemini AI Spintax Generator** untuk personalisasi dinamis, serta **Mode Warm-Up SMTP Otomatis**.
